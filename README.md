This is an autorigger I created as practice to create a specific IK joint chain setup for a lab assignment at SFU.
It prompts the user to assign names to a set of 3 proxies, which, once created after hitting the "create proxies" button, the user can move around in the scene. 
Once the user is content with their locations, they can hit the "finalize rig" button to create a chain of 3 chains at the 3 proxies' locations, an IK RP Handle,
an IK controller to control the arm, and a pole vector controller.
